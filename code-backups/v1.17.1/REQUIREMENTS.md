# Requirements & Specifications — PaySick v1.17.1

**Version**: 1.17.1
**Date**: 2026-10-26

Carries forward all requirements from v1.17.0 and adds the following.

## New Requirements
| ID | Requirement | Priority |
|----|-------------|----------|
| DES-01 | Every homepage section has its own theme, and neighbouring sections never share one; at least two sections are dark | Must Have |
| DES-02 | Every section after the hero has an eyebrow label and opens with a curved divider | Should Have |
| DES-03 | Decorative artwork is `aria-hidden` | Must Have |
| DES-04 | `prefers-reduced-motion` disables all animation and scroll-reveal | Must Have |
| DES-05 | Scroll-reveal never hides content unless JavaScript has opted in | Must Have |
| DES-06 | All text meets WCAG AA contrast (4.5:1) against its section background | Must Have |

## Inherited Requirements
All requirements from v1.17.0 remain in effect. See [v1.17.0/REQUIREMENTS.md](../v1.17.0/REQUIREMENTS.md).

## Deprecated Features
None.
